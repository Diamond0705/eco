# UI-экраны

Интерфейс EcoLogist в MVP только на русском языке.

## Менеджер

- Регистрация.
- Вход.
- Список заявок.
- Создание заявки.
- Карточка заявки.
- Сравнение маршрутов с таблицей и Leaflet-картой.
- Список рейсов.
- Карточка рейса.
- Аналитика по завершенным рейсам.

## Администратор

- Пользователи.
- Транспорт.
- Экологические стандарты.
- Локации.
- Настройки расчета.

## Phase 0

В Phase 0 создается только базовый шаблон `templates/base.html`. Полные экраны будут добавлены позже.
