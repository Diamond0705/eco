# PMI mapping

Этот файл связывает будущую реализацию с проверками программы и методики испытаний.

## Основные проверки MVP

- Менеджер может зарегистрироваться и войти.
- Менеджер создает заявку.
- Заявка содержит груз, вес, дату, транспорт и точки маршрута.
- Система создает 3 route options через `MockRouteProvider`.
- Таблица маршрутов и Leaflet-карта отображают одинаковые варианты.
- Утверждение маршрута создает `Trip`.
- Статусы рейса меняются вручную.
- PDF-путевой лист создается.
- Аналитика показывает завершенные рейсы и суммарные выбросы.
- PDF-отчет аналитики создается.
- Администратор управляет справочниками.

## Phase 0

Проверяется только готовность скелета проекта:

- Django импортируется.
- Custom user настроен.
- Миграции создаются.
- Smoke-тесты запускаются.
- Ruff проходит.
