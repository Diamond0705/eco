# Архитектура

EcoLogist строится как Django-монолит:

- Django views, forms, templates и services находятся в одном проекте.
- Бизнес-логика выносится в сервисные классы.
- Шаблоны не содержат бизнес-расчетов.
- PostgreSQL используется как основная база данных.
- Leaflet используется только для отображения маршрутов.
- ReportLab используется для PDF на следующих фазах.

## Приложения

- `accounts` - custom user, роли, регистрация и вход.
- `fleet` - транспорт, экостандарты, настройки расчета.
- `locations` - predefined-точки Москвы и Московской области.
- `orders` - заявки на перевозку.
- `routing` - варианты маршрутов, providers, расчет маршрутов и выбросов.
- `trips` - утвержденные рейсы и история статусов.
- `reports` - PDF-путевые листы и PDF-аналитика.
- `dashboard` - стартовые страницы менеджера и администратора.
- `core` - общие утилиты, permissions и seed-команды.

## Phase 0

В Phase 0 создается только каркас. Бизнес-логика приложений, маршруты, PDF и расчеты не реализуются.
