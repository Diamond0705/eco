# Workflow для Codex

Работать поэтапно. Не пытаться реализовать весь EcoLogist одной задачей.

## Правила

- Читать `AGENTS.md` перед изменениями.
- Держать MVP простым.
- Не добавлять запрещенные технологии.
- Не менять архитектуру без отдельного согласования.
- Не переносить бизнес-логику в шаблоны.
- Все UI-лейблы писать на русском.
- Для моделей создавать миграции.
- Для рискованных изменений добавлять тесты.

## Команды проверки

```powershell
python manage.py check
python manage.py makemigrations
python manage.py migrate
pytest
ruff check .
```

## Phase 0

Phase 0 создает структуру, настройки, custom user и smoke-тесты. Бизнес-логика не реализуется.
